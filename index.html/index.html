Development Reflection

Learning programming has not been easy for me. At the beginning, even a small mistake in spelling, punctuation, or file paths could stop the entire page from working. I had to learn how to slow down, read error messages carefully, and test one part of the project at a time. HTML helped me understand structure, CSS challenged me to think about design, and JavaScript pushed me to think more logically.

Even though the process was sometimes frustrating, finishing a programming project gave me a kind of happiness and pride that is hard to describe. Seeing a page change from plain text into a real website made me feel that my effort was visible. This project taught me that programming is not only about writing code; it is also about patience, problem solving, creativity, and the confidence to keep trying.
