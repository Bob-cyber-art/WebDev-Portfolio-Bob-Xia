Design Thinking Process

How I planned, designed, tested, and improved this portfolio website.

1. Empathize

I considered what a teacher, classmate, or future reviewer would need: clear navigation, readable content, and evidence of HTML, CSS, and JavaScript skills.

2. Define

The main problem was creating a website that is personal, organized, accessible, and strong enough to show my learning in one portfolio.

3. Ideate

I planned sections for my introduction, skills, hobbies, Zero Hunger, accessibility, and development reflection before writing the final layout.

4. Prototype

I built the first version with HTML and CSS, then added animations, cards, responsive layout, and JavaScript interactions.

5. Test

I checked that the navigation works, the form validates input, the modal opens and closes, and the layout remains readable on smaller screens.
