Written Reflection

Reflection

Learning programming has not been easy for me. At the beginning, even a small mistake in spelling, punctuation, or file paths could stop the entire page from working. I had to learn how to slow down, read error messages carefully, and test one part of the project at a time. HTML helped me understand structure, CSS challenged me to think about design, and JavaScript pushed me to think more logically. Sometimes I felt frustrated because the page did not look the way I imagined, or an interaction did not work the first time I tried it.

However, every challenge also helped me improve. I learned that programming is a process of patience, testing, and problem solving. When I finally completed a section or fixed a bug, I felt a strong sense of progress. Finishing this project gave me a kind of happiness and pride that is hard to describe, because I could see my work become a real website. This experience showed me that web development is not only about code; it is also about creativity, communication, and confidence. I am proud of this portfolio because it represents both what I have learned and the effort I put into improving.
